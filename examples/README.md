# Ví dụ: Báo cáo Q3

Chạy `python examples/build_example.py` để sinh 3 file từ
`data.json` qua orchestrator, kèm audit bằng code.

Số liệu mẫu đã kiểm chứng: tổng doanh thu 1.050 = 520 + 380 + 150;
tổng chi phí 660 = 310 + 260 + 90; lợi nhuận 390 = 1.050 - 660.
Trong Excel, các tổng này là công thức liên kết Data → Summary,
không phải số gõ tay.
